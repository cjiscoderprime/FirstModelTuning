# FirstModelTune

A hands-on project exploring pretrained models and fine-tuning using Hugging Face Transformers and PyTorch.

## Objectives

- Understand pretrained model architecture and inference.
- Prepare and tokenize training datasets.
- Fine-tune a pretrained model.
- Evaluate model performance before and after fine-tuning.
- Publish the fine-tuned model on Hugging Face.

## Technology Stack

- Python
- PyTorch
- Hugging Face Transformers
